This is Task Management Application



Environment variables:
First, create the environment variables file .env in the backend folder. The .env file contains the following environment variables:

MONGODB_URI = your MongoDB URL
JWT_SECRET = any secret key 
PORT = 5000 

Application Run Process:

Backend:
1. Open the project in any editor of choice.
2. Navigate into the backend directory cd backend.
3. Run npm install to install the packages.
4. Run  node server.js to start the server.

Frontend:
1. Open the project in any editor of choice.
2. Navigate into the frontend directory cd frontend.
3. Run npm run dev to run the app on http://localhost:3000.
4. Open http://localhost:3000 to view it in your browser.
